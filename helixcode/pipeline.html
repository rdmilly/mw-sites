Compression engine4-layer pipeline: ① Pattern Ref — replace patterns with §symbols ② Boilerplate Dedup — collapse repeated imports ③ Shorthand — abbreviate common terms ④ Context Pruning — remove low-relevance content. Versioned dictionary — decompression always uses matched expansion

Shard assemblerBuilds context shards via diff chains — not full state. DELTA mode = base_summary + diffs since last session. Cost scales with recency of change, not project size. SNAPSHOT on first access or >80% budget changed

Forge relationship: The Forge runs on the helix Docker network (co-located, peer service) but has its own compose at /opt/projects/the-forge/. The Membrane service inside Cortex syncs atoms from Forge into Helix Postgres/ChromaDB. helix-mcp proxies atom catalog tools to http://the-forge:9095 directly.  |  MCP pipeline (Provisioner, mcp-root-proxy, mcp-provision-filter) is external routing infrastructure — Helix runs fully without it.  |  Provisioner registers helix-mcp as one of 45 servers.
